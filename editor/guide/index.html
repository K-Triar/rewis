1. はじめに

REWIS（Kトライア全世界鉄道情報システム）は、Minecraft（マイクラ）のサーバー内にある鉄道網の乗換案内と運行情報を提供するシステムです。この表形式エディタでは、利用者が乗換案内や運行情報を見るときに使う元データを作成・管理します。

REWISには、データを表で編集する「表形式エディタ」と、図の上で直接操作して編集する「図形式エディタ」の2つがあります。どちらも扱うデータは同じです。サーバーに保存してあれば、どちらのエディタで開いても同じ内容が表示されます。表形式エディタは、登録済みのデータを一覧で見比べながら1件ずつ確認・修正したいときに向いています。

開き方

次のいずれかの方法で開きます。

  • 公開ページのメニューにある「事業者向けページ」を押します。
  • ブラウザで直接次のURLを開きます。
    https://k-triar.github.io/rewis/editor/

図形式エディタからは、状態の行にある［表形式で編集］を押すと移動できます。同じタブの中で移動した場合は、ログインした状態がそのまま引き継がれます。

次の章2. 準備：ログインとデータの読み込み

2. 準備：ログインとデータの読み込み

編集を始める前に、システムから最新のデータを読み込みます。まだデータを読み込んでいないときは、画面に「路線データ編集を始める」という案内が表示されます。ただし、「データの読込と書出」タブを開いているときは表示されません。

案内は「① ログイン」「② データを読み込む」の2段になっています。案内の一番下の［操作マニュアル］を押すと、このマニュアルを新しいタブで開けます。画面の案内に従って次のように進めます。

  1. ① ログイン
    • 「ユーザーID」「パスワード」を入力し、［ログイン］を押します。
    • 接続先のサーバー（Workers API URL）は最初から設定されているので、通常は入力不要です。変更が必要な場合だけ、［詳細設定］を開いて書き換えます。
    • すでにログインしている場合は入力欄が表示されず、「<ユーザーID> でログイン中」と表示されます。
  2. ② データを読み込む
    • ［路線網と運行情報を読み込む］を押します。ログインするまでこのボタンは押せません。
    • 読み込みが完了すると、編集画面が表示されます。開いていたタブがそのまま表示され、初めて開いたときは「駅」タブが表示されます。
    • サーバーにまだデータがない場合や、ログインの期限が切れている場合は、画面にその旨を伝えるメッセージが表示されます。

Note

読み込んだデータは、開いているブラウザのタブの中にだけ保持されます。ページを再読み込みしたりタブを閉じたりすると、読み込んだデータは消え、もう一度読み込み直す必要があります。なお、ログインした状態は、同じタブであればログインの有効期限まで残ります。

次の章3. 画面の見方

3. 画面の見方

ヘッダー（画面最上部）

ページの名前（路線データ編集システム）が表示されます。左端の REWIS のロゴを押すと、REWIS のホームが新しいタブで開きます（編集中の画面はそのまま残ります）。右側にある［操作マニュアル］を押すと、このマニュアルが新しいタブで開きます（編集中の画面はそのまま残ります）。ログイン中は、その右に「<ユーザーID> でログイン中」と［ログアウト］ボタンが表示されます。

ログアウトしたいときは、［ログアウト］を押します。未保存の変更がある場合は確認ダイアログが表示されます。
ログアウトすると「路線データ編集を始める」の画面に戻りますが、読み込んだデータや未保存の変更は消えません。再度ログインして［編集を続ける］を押せば、そのまま作業を再開できます。
未保存の変更を破棄して最新のデータを読み込み直したいときは、隣にある［サーバーから読み込み直す］を押します。
なお、変更内容をサーバーに保存するには再ログインが必要です。

状態の行（ヘッダーの下）

編集内容の保存状態やエラーの件数が表示されます。

  • 「路線網 版 N」「運行情報 版 N」：現在読み込んでいるデータの版数（保存するたびに1つ増える番号）です。読み込んでいない間は「未読込」と表示されます。
  • 「未保存の変更あり」：まだサーバーに保存していない変更があるときに、路線網・運行情報それぞれの横に表示されます。
  • ［エラー N］［注意 N］：データに問題がある件数です。押すとエラーや注意の一覧が開きます。
  • ［サーバーに保存］：編集内容をサーバーに保存します。未保存の変更がないときは押せません。
  • ［図形式で編集］：図形式エディタに画面を切り替えます。

タブ

状態の行の下にタブが並んでいます。
左から「駅」「路線」「運行系統」「乗換・駅グループ」「運行情報」「鉄道会社」「車両種別」「履歴」「データの読込と書出」の順に並んでいます。

開いているタブはページのURLに記録されるため、ブラウザの「戻る」「進む」でもタブを切り替えられます。

Note

「種別」の呼び分けについて
画面に「種別」と表示されるのは、急行や普通といった利用者に案内するための種別（案内種別）です。一方、TrainCarts・新幹線・トロッコなどの列車の仕組みは「車両種別」と呼びます。このガイドでは、画面の項目名どおり案内種別を「種別」、列車の仕組みを「車両種別」と書き分けています。

一覧と編集フォーム

駅・路線・運行系統・乗換・駅グループ・運行情報は、どれも「一覧表」と「編集フォーム」の組み合わせで編集します。

  • 一覧表：登録されているデータが1件1行で表示されます。一覧が長いときは、一覧の中だけがスクロールします。
  • 編集フォーム：一覧の行の［詳細］を押すか、見出しの右にある［+ 追加］を押すと開きます。編集中の行は一覧で色が付きます。
    画面の幅が広いときは一覧の右側にフォームが開きますが、運行系統タブはフォームの横幅が広いため一覧の上に開きます。また、スマートフォンなど画面の幅が狭いときは、どのタブでも一覧の上にフォームが開きます。

どのタブでも共通の操作

  • ［+ 追加］：見出しの右にあります。新しく登録するための空のフォームが開きます。
  • ［詳細］／［閉じる］：一覧の各行の右端にあります。［詳細］を押すとその行の編集フォームが開き、同じ行の［閉じる］を押すとフォームが閉じます。
  • ［削除］：一覧の各行の右端にあります。押すと、その行が確認の表示に変わります（「4. 編集と保存の基本ルール」の「削除のルール」を参照）。
次の章4. 編集と保存の基本ルール

4. 編集と保存の基本ルール

最初に知っておくこと

編集を始める前に、次の3つを確認しておいてください。

  1. 保存は2段階で行います：フォームの［保存］（新しく作るときは［追加する］）を押して画面に反映させ、最後に状態の行の［サーバーに保存］を押してサーバーへ保存します。
  2. エラーが1件でもあると保存できません：データの中にエラーがあると、サーバーに保存できません。エラーをすべて修正してから保存します。
  3. 元に戻す機能はありません：直前の操作を取り消す機能はないため、誤って変更したときの対処法をあらかじめ確認しておきます（「操作を間違えたとき」を参照）。

保存は「フォームの保存」と「サーバーへの保存」の2段階

表形式エディタでは、編集内容が次の2段階で確定します。

  1. フォームの［保存］（新規の場合は［追加する］）
    フォームで入力した内容は、フォームの一番下にある［保存］（新しく作るときは［追加する］）を押すまで、一覧やデータに反映されません。［保存］を押すとフォームの内容がチェックされ、問題があればメッセージが表示されて反映されません。
    なお、乗換・駅グループタブの「乗換の既定値」と、鉄道会社タブの「会社名」の2つは［保存］ボタンがなく、入力欄から抜けるとすぐに反映されます（「5.5 乗換・駅グループ」および「7.1 鉄道会社」を参照）。
  2. 状態の行の［サーバーに保存］
    フォームの［保存］を押した段階では、変更は開いているブラウザの中だけに一時的に反映されている状態です。状態の行に「未保存の変更あり」と表示されます。状態の行の［サーバーに保存］を押すとサーバーに保存され、ほかの人にも見えるようになります。

Warning

  • フォームの［保存］を押す前に次のような操作をすると、フォームに入力していた内容は確認なしで破棄されます。
    • フォームの［キャンセル］を押す（運行情報のフォームの［キャンセル］だけは確認ダイアログが表示されます）
    • 一覧の［閉じる］を押す
    • 別の行の［詳細］や［+ 追加］を押す
    • 別のタブに切り替える
  • 状態の行の［サーバーに保存］を押すまで、変更はサーバーには保存されず、ほかの人にも見えません。保存しないままブラウザを閉じたり再読み込みしたりすると、編集した内容は失われます（未保存の変更があるときは、ブラウザが確認を表示します）。

入力のチェック

フォームの［保存］（［追加する］）を押したとき、必須の項目が空だったり、IDの書式が正しくなかったりすると、メッセージが表示されて反映されません。メッセージの内容に従って修正してから、もう一度［保存］を押します。

ID（駅ID、のりばID、路線ID、種別ID、会社ID）は、半角の英数字、アンダースコア（_）、ハイフン（-）のみを使い、1〜64文字で入力します。同じ種類のデータの中で同じIDは使えません。

削除のルール

一覧の行の［削除］を押すと、その行が確認の表示に変わります。

  • 削除できるとき：［削除する］を押すと削除されます。やめたいときは［キャンセル］を押します。
  • 削除できないとき：駅や路線など、ほかの場所から使われているデータは削除できません。行に「削除できません。参照箇所: 」と、使っている場所の一覧が表示されます。一覧の項目をクリックすると、その場所（該当するタブの編集フォーム）へ移動できます。ただし、運行情報から使われている場合はそこから移動できないため、運行情報タブを開いて対象の運行情報を探してください。表示を閉じるときは［閉じる］を押します。

たとえば、路線に含まれている駅や、運行系統で使われている路線などはそのままでは削除できません。先にそれらを使っている側を外したり変更したりしてから削除します。

フォームの中の表（のりば、種別、駅順、停車駅、駅グループの駅）の行にある［削除］を押すと、確認なしでフォームの中から消えます。この場合も、フォームの［保存］を押すまでは反映されないため、誤って消したときは［キャンセル］でフォームを閉じれば元の状態に戻せます。

エラーと注意の一覧

状態の行の［エラー N］または［注意 N］を押すと、画面にエラーや注意の一覧が開きます。

  • 一覧の上部にある［エラー］［注意］を押して表示を切り替えます。閉じるときは右上の［×］を押すか、キーボードの Esc キーを押します。
  • 各行には、問題の内容と「場所: 」が表示されます。行をクリックすると該当するタブに移動し、問題のあるデータの編集フォームが開きます（場所によっては移動しない場合もあります）。
  • エラー（赤）：1件でもあるとサーバーに保存できません。該当の行をクリックしてエラーのある場所へ移動し、内容を修正してください。
  • 注意（オレンジ）：残っていても保存できますが、内容を確認することをお勧めします。たとえば、のりばを指定していない停車駅や、停車する有効な運行系統がない駅などが注意になります。

保存できないときの原因と対処法

状態の行の［サーバーに保存］が押せない、または保存に失敗する場合は、次の原因を確認します。

  • 未保存の変更がない場合：未保存の変更がないときはボタンを押せません。
  • データにエラーがある場合：データの中にエラーが1件でもあると、「「路線網」にエラーが N 件あるため保存できません。」のようなメッセージが表示されます。［OK］を押すとエラーの一覧が開くので、前述の「エラーと注意の一覧」の手順でエラーのある場所へ移動し、内容を修正してください。
  • ログインの期限が切れている場合：「ログインの有効期限が切れました。もう一度ログインしてください。」と表示され、［OK］を押すとログインの画面に戻ります。編集中のデータは残っているので、再度ログインして［編集を続ける］を押し、もう一度［サーバーに保存］を押します。
  • ほかの人が先に保存していた場合：自分が編集している間にほかの人が先にサーバーへ保存した場合、内容の上書きを防ぐためそのままでは保存できません。確認ダイアログに「ほかの人が先に保存しました（最新は版 N）。今の変更をファイルに書き出してから、読み込み直してください。」と表示され、［ファイルに書き出す］ボタンが出ます。次の手順で対応します。
    1. ［ファイルに書き出す］を押して、編集中のデータをパソコンに保存します。
    2. 「データの読込と書出」タブ（「7.4 データの読込と書出」を参照）を開き、書き出されたファイルが network.json なら「サーバーから読み込む: 路線網」の、operations.json なら「サーバーから読み込む: 運行情報」の［読み込む］を押して最新のデータを読み込み直します。読み込み直すと自分の未保存の変更は画面から消えます。
    3. 書き出したファイルの内容を見ながら、最新のデータに自分の変更をもう一度加えてから、［サーバーに保存］を押します。

    書き出したファイルをそのまま「データの読込と書出」タブの［ファイルから読み込む］で読み込んで保存すると、ほかの人が保存した変更を消してしまうため避けてください。

保存に成功すると、状態の行の下に「保存しました。」と数秒間表示され、版数が1つ増えます。

操作を間違えたとき

表形式エディタには、操作を元に戻す（Ctrl+Z）・やり直す機能はありません。また、画面上に吹き出しで案内を出す［操作ガイド］もありません。これらは図形式エディタだけの機能です。

表形式エディタで誤った操作をした場合は、次の方法で対処します。

  • フォームを保存する前：フォームの［キャンセル］を押してフォームを閉じれば、入力前の状態に戻ります。
  • フォームを保存したが、まだサーバーに保存していない場合：「データの読込と書出」タブでサーバーから最新のデータを読み込み直します。ただし、未保存の変更はすべて消えます。
  • すでにサーバーに保存してしまった場合：「履歴」タブから以前の版を呼び出します（「7.3 履歴」を参照）。

元に戻す操作を使いながら作業したいときは、図形式エディタを使います。

次の章5. 作業の流れ

5. 作業の流れ

REWISで新しく鉄道のデータを整えるときは、次の順序で作業を進めます。

  1. 自分の会社が登録されているか確認する（鉄道会社タブ）
  2. 駅を作る（駅タブ）
  3. 路線を作り、駅を登録する（路線タブ）
  4. 運行系統を作り、停車駅や駅間の所要時間を設定する（運行系統タブ）
  5. 必要に応じて乗換時間や駅グループを設定する（乗換・駅グループタブ）

5.1 路線を作る前の確認（鉄道会社）

新しい路線を作るときは、その路線を運営する鉄道会社を割り当てます。
路線を作り始める前に「鉄道会社」タブを開き、自分の鉄道会社が一覧に登録されているか確認してください。
まだ登録されていない場合は、鉄道会社タブで会社を追加します（追加手順は「7.1 鉄道会社」を参照）。

5.2 駅（駅タブ）

駅の基本情報（ID、駅名、かな、のりば）を登録します。

画面の見方

  • 検索欄：「駅名・かなで検索」と書かれた欄に駅名かかなの一部を入力すると、一覧が絞り込まれます。
  • 一覧：「駅ID」「駅名」「かな」「のりば数」が表示されます。各行の右端に［詳細］［削除］があります。

駅を新しく作る手順

  1. 見出しの右にある［+ 追加］を押します。「駅を追加」のフォームが開きます。
  2. 「駅ID」「駅名」「かな」を入力します。
    • 駅ID：半角の英数字、アンダースコア（_）、ハイフン（-）のみを使い、1〜64文字で入力します（例：KL01）。ほかの駅と同じIDは使えません。登録済みの駅IDはほかの設定でも使われるため、作成した後は変更できません。
    • 駅名：駅の名前を入力します。次のルールに従って入力してください。
      • 空にはできません。
      • 場所は同じでも会社によって駅名が違う場合は、別々の駅として2つ登録してください（そのうえで2つの駅の間に乗換を登録し、必要に応じて駅グループにまとめます）。
      • まったく別の駅で偶然名前が同じになる場合は、利用者が区別できるように「駅名（場所）」のように工夫して入力してください。
    • かな：駅名の読み仮名を入力します。検索で見つけやすくするため、カタカナやアルファベットが含まれている駅名でも、すべてひらがなで入力します。
  3. 必要に応じて、このフォームの中でのりばも追加します（「のりばの管理」を参照）。
  4. ［追加する］を押します。一覧に駅が追加され、フォームが閉じます（やめたいときは［キャンセル］を押します）。

のりばの管理

列車が発着するのりばを、駅のフォームの「のりば」の表で管理します。のりばの変更も、フォームの［保存］（新規の駅は［追加する］）を押した時点で反映されます。

  • 追加する：表の下にある「のりばID」と「表示名」の欄に入力し、［+ のりば追加］を押します。のりばIDと表示名はどちらも必須です。のりばIDの書式は駅IDと同じで、同じ駅の中で同じIDは使えません。
  • 名前やIDを変更する：表の「のりばID」「表示名」の入力欄を書き換えます。ただし、運行系統や乗換ですでに使われているのりばのIDを書き換えると、使っている側からそののりばが見つからなくなりエラーになります。使われているのりばの名前を変えたいときは、IDは変えずに「表示名」だけを書き換えてください。
  • 並べ替える：各行の［▲］［▼］を押して1つずつ上下に動かして並べ替えます（のりばの表ではドラッグによる並べ替えはできません）。
  • 削除する：各行の［削除］を押します。運行系統や乗換で使われているのりばは削除できません。使われている場合は行に「削除できません。参照箇所: 」と使っている場所の一覧が表示され、クリックすると該当の場所へ移動できます。

駅の変更と削除

  • 駅名やかなを変更したいときは、一覧の［詳細］を押してフォームを開き、入力欄を書き換えて［保存］を押します。駅IDは変更できません。
  • 駅を削除したいときは、一覧の［削除］を押します。どこからも使われていない駅だけ削除できます。使われている場合は、使っている場所（路線の駅順、運行系統の停車駅、乗換、駅グループ、運行情報の範囲）が表示されます。

Note

図形式エディタで使う駅の図の上の位置は、表形式エディタでは設定できません。駅の位置を調整したいときは、図形式エディタを使います。

5.3 路線（路線タブ）

路線の名前や色、どの駅をどの順番で通るか（駅順）、路線の形を決めます。

画面の見方

一覧には「路線ID」「路線名」「会社」「色」「車両種別」「駅数」「種別数」「形状」が表示されます。形状は「普通」「環状線」「ラケット型」のいずれかです。

路線を新しく作る手順

  1. 見出しの右にある［+ 追加］を押します。「路線を追加」のフォームが開きます。
  2. 「路線ID」「路線名」「会社」「色」「車両種別」を入力・選択します（各項目は「路線の設定項目」を参照）。
  3. 「種別」の表に種別を1つ以上追加します（追加しないと［追加する］を押したときに「種別を1つ以上追加してください。」と表示されます）。
  4. 「駅順」の表に、路線に含める駅を順番に追加します。
  5. 必要に応じて「形状」と「方向名」を設定します。
  6. ［追加する］を押します（やめたいときは［キャンセル］を押します）。

路線の設定項目

  • 路線ID：半角の英数字、アンダースコア（_）、ハイフン（-）のみを使い、1〜64文字で入力します（例：KT-L）。作成した後は変更できません。
  • 路線名：空にはできません。
  • 会社：一覧から運営する鉄道会社を選びます。途中で運営会社が変わる路線は、会社ごとに分けて別路線として登録してください。
  • 色：色の欄を押して、路線の色を選びます。
  • 車両種別：走らせる列車の方式（TrainCarts、新幹線、トロッコ）を選びます。同じ線路で違う車両種別が走っている場合は、別路線としてもう1つ登録してください。
  • 種別（案内種別）：急行や各駅停車など、利用者に案内する列車種別の一覧です。1路線につき最低1つの種別が必要です。
    • 追加する：表の下にある「種別ID」と「種別名」の欄に入力し、［+ 種別追加］を押します。種別IDの書式は路線IDと同じで、同じ路線の中で同じIDは使えません。
    • 名前を変更する：表の「名前」の入力欄を書き換えます。
    • IDを変更する：「ID」の欄を書き換えられるのは、まだフォームの［保存］を押していない（追加したばかりの）種別だけです。一度保存した種別のIDは変更できません。
    • 並べ替える：各行の［▲］［▼］を押すか、行をドラッグして並べ替えます。
    • 削除する：各行の［削除］を押します。運行系統や運行情報で使われている種別は削除できず、使っている場所の一覧が表示されます。
  • 駅順：路線が通る駅を順番に並べた表です。「#」の列には、先頭を0とした駅の番号が表示されます。
    • 駅を追加する：表の下にある「駅名・かなで検索」と薄く書かれた検索欄を使います。駅名かかなの一部を入力すると候補（「駅名（駅ID）」の形、最大20件）が下に表示されるので、クリックして選びます。選んだ駅は駅順の末尾に追加されます。
    • 並べ替える：各行の［▲］［▼］を押すか、行をドラッグして並べ替えます。途中に入れたい駅は、一度末尾に追加してから並べ替えて目的の位置へ動かします。
    • 路線から外す：各行の［削除］を押します。
  • 形状：次の3つから選びます。
    • 普通の路線：両端に終点がある形です。
    • 環状線：輪になっている形です。駅順の最後の駅の次は、最初の駅に戻ります。
    • ラケット型：線の先が輪になっていて、終点から手前のどこかの駅に戻る形です。選ぶと「戻る駅: 」の選択欄が表示されるので、終点から戻る先の駅（「番号: 駅名（駅ID）」の形）を選びます。
  • 方向名：画面には「forward（駅順どおり）」「backward（逆向き）」と英語混じりの項目名で表示されます。「forward（駅順どおり）」には駅順どおりに進む向きの名前、「backward（逆向き）」には逆向きに進む向きの名前を入力します（例：下り線／上り線、外回り／内回り）。新しい路線では「下り線」「上り線」があらかじめ入っています。
    • 形状で「環状線」を選ぶと、［外回りにする］［内回りにする］のボタンが表示されます。［外回りにする］は「forward（駅順どおり）」の向きの名前を「外回り」に、［内回りにする］は「backward（逆向き）」の名前を「内回り」に書き換えます。環状線を選んだだけでは向きの名前は自動で変わらないため、必要に応じて押してください。

Warning

  • すでに駅順にある駅を検索欄から選ぶと、「同じ駅が既に駅順に含まれています」というメッセージが出ますが、駅はそのまま追加されます。1つの路線の駅順に同じ駅が2回あるとエラーになり、サーバーに保存できません。不要な行は［削除］で外してください（ラケット型でも同じ駅を2回入れる必要はありません。戻る先は「戻る駅」で指定します）。
  • 駅順から駅を外しても、確認は出ません。その駅に停まる運行系統があると、運行系統にエラーが出ることがあります。外したあとは状態の行の［エラー N］を確認してください。

路線の変更と削除

  • 路線の設定を変更したいときは、一覧の［詳細］を押してフォームを開き、書き換えて［保存］を押します。
  • 路線を削除したいときは、一覧の［削除］を押します。運行系統や運行情報で使われていない路線だけ削除できます。

5.4 運行系統（運行系統タブ）

列車が停まる駅の順序や、駅間の所要秒数、駅間ごとの路線・種別を決めます。乗換案内では、1つの運行系統を1本の列車として扱います。

画面の見方

  • 絞り込み：「路線で絞込」で路線を選ぶと、その路線を通る運行系統だけが表示されます。路線を選ぶと「種別で絞込」も選べるようになり、その路線の特定の種別で走る運行系統に絞り込めます。
  • 一覧：「行先」「区間」「停車数」「所要時間」「有効」「警告」が表示されます。
    • 行先：環状運転の系統は「（環状）」と表示されます。
    • 区間：走る路線と種別が「路線名 種別名 → 路線名 種別名」のように順に表示されます。
    • 所要時間：駅間の秒数の合計です。
    • 有効：「有効」または「無効」が表示されます。
    • 警告：その運行系統に出ている注意（オレンジ）の件数です。エラーの件数は含まれないため、エラーは状態の行の［エラー N］で確認します。
  • 各行の右端に［詳細］［複製］［逆方向を作成］［削除］があります。
  • このタブだけは、編集フォームが一覧の上に開きます。

運行系統を新しく作る手順

  1. 見出しの右にある［+ 追加］を押します。「運行系統を追加」のフォームが開きます。
  2. フォーム上部の「行先」「メモ」「有効」「環状」を設定します（「フォーム上部の設定」を参照）。表形式エディタでは行先は自動で入らないため、終点の駅名などを入力します。
  3. 「停車駅」の表の下にある「駅名・かなで検索」の欄で、始発駅から順に停車駅を選んで追加していきます。選んだ駅は表の末尾に追加されます（駅の検索方法は「5.3 路線」を参照）。
  4. 各停車駅の行で、のりば・乗車可・降車可・秒数・路線・種別を確認し、必要に応じて修正します（初期値や各列の内容は「停車駅の表の各列」を参照）。
  5. フォーム下部の「プレビュー」で、停車駅の並びと路線の切り替わりを確認します。
  6. ［追加する］を押します（やめたいときは［キャンセル］を押します）。停車駅が2つ未満の場合や、環状運転でないのに行先が空の場合は、メッセージが表示されて追加されません。

フォーム上部の設定

  • 「行先」：案内に表示する行先です。環状運転のときは入力できません。
  • 「メモ」：編集画面の中だけで使うメモです（任意）。利用者には表示されません。
  • 「有効」：チェックを外すと「無効」になり、データを削除することなく乗換案内の検索や表示の対象から外せます。無効の運行系統があると、注意（オレンジ）が表示されます。
  • 「環状」：環状運転にするときにチェックを入れます（「特殊な運行の設定」を参照）。

停車駅の表の各列

停車駅の表は、1行が1つの停車駅です。各行の「秒数」「路線」「種別」は、その駅から次の停車駅までの区間の設定です。最後の行は次の駅がないため、「秒数」は入力できず、「路線」「種別」も表示されません（環状運転の場合を除きます）。

駅を追加した直後は、初期値として次の設定が入ります。

  • のりば：「（指定なし）」
  • 秒数：60秒
  • 乗車可・降車可：どちらもオン
  • 路線・種別：1つ前の駅間と同じ路線・種別（最初の駅間は、路線一覧の先頭にある路線とその先頭の種別）

各列の設定内容は次のとおりです。

  • #：先頭を0とした停車駅の番号です。
  • 駅：停車駅の駅名です。
  • のりば：その駅で使うのりばを選びます。「（指定なし）」のままにすると注意（オレンジ）の対象になります。
  • 乗車可：オンにすると、その駅から乗れます。降車専用の駅にしたいときはチェックを外します。
  • 降車可：オンにすると、その駅で降りられます。乗車専用の駅にしたいときはチェックを外します。
  • 秒数：その行の駅から次の停車駅に着くまでの秒数です（運行系統全体の始発から終点までの秒数ではありません）。停車時間を含めた秒数を、0以上の整数で入力します。車両種別ごとに次のように測ります。
    • TrainCarts：その駅で列車が停車した瞬間から、次の停車駅で列車が停車した瞬間までを測ります。列車がその駅で出現する場合は、出現した瞬間から測ります。
    • 新幹線：その駅を通過した瞬間から、次の停車駅を通過した瞬間までを測ります。ただし、その駅が運行系統の始発駅のときはボートを動かし始めた瞬間から、次の停車駅が運行系統の終点のときはボートが停止した瞬間までを測ります。
    • トロッコ：その駅のボタンを押した瞬間から、次の停車駅で列車が停車した瞬間までを測ります。自動で発車する駅では、列車が動き始めた瞬間から測ります。
  • 路線：その駅から次の停車駅までの駅間で走る路線を選びます。選択欄には、その行の駅を駅順に含む路線が表示されます。次の停車駅も駅順に含む路線を選んでください（含まない路線を選ぶとエラーになります）。
  • 種別：その駅間で使う種別（案内種別）を選びます。路線を選び直すと、その路線の先頭の種別に変わります。

駅間ごとに違う路線を選ぶと、別々の路線がつながって直通運転する設定になります。

停車駅の並べ替えと削除

  • 並べ替える：各行の［▲］［▼］を押すか、行をドラッグして並べ替えます。行を動かすと、その行の路線・種別の設定も一緒に動くため、並べ替えたあとは各行の路線・種別と秒数を確認してください。
  • 途中に駅を入れる：検索欄で駅を選んで末尾に追加してから、並べ替えて目的の位置に動かします。
  • 削除する：各行の［削除］を押します。削除した駅の前後の駅がつながり、その駅間には削除した駅の1つ前の駅間の路線・種別が引き継がれます。1つの系統に停車駅は2つ以上必要です。

プレビュー

フォーム下部の「プレビュー」には、停車駅が順に並んで表示されます。各駅の左側には、その駅から出る駅間の路線の色の線が付きます。路線または種別が前の駅間から切り替わる駅には「［直通］」と表示されます。

特殊な運行の設定

  • 環状運転：
    「環状」にチェックを入れると、次のように変わります。
    • 「行先」が空になり、入力できなくなります。
    • 「環状区間の路線」と「種別」の選択欄が表示されます。環状運転では、すべての駅間が同じ路線・種別になるため、ここで1つだけ選びます。各行の「路線」「種別」の列は表示されなくなります。
    • 最後の行の「秒数」も入力できるようになります。ここには、最後の停車駅から最初の停車駅に戻るまでの秒数を入力します。停車駅の表の最後に、最初の駅をもう一度追加する必要はありません。
  • 分岐運転（途中で行き先が分かれる列車）：運行系統は1本の停車駅の並びとして設定します。途中で行き先が分かれる列車は、行き先ごとに別々の運行系統を作成してください。

一覧の行のボタン

  • ［複製］：同じ内容の運行系統をもう1つ作成します。確認なしですぐに一覧に追加され、複製した運行系統のフォームが開きます。メモの末尾には「（複製）」が付きます。
  • ［逆方向を作成］：逆向きに走る運行系統を自動で作成し、すぐに一覧に追加します。作成後に「逆方向の運行系統を作成しました。のりばを確認してください。」と表示され、作成した運行系統のフォームが開きます。
    • 逆向きになるもの：停車駅の順番、駅間の秒数、駅間の路線・種別、行先（元の運行系統の始発駅名）。
    • 元のまま引き継がれるもの（必ず確認が必要）：各停車駅ののりば、「乗車可」「降車可」の設定。作成後は、逆向きの列車が使うのりばや乗車・降車の設定を必ず確認し、［保存］を押してください。
  • ［削除］：行に、その運行系統の行先を含んだ「「○○」を削除しますか？」という確認が表示されるので、［削除する］を押すと削除されます。

5.5 乗換・駅グループ（乗換・駅グループタブ）

同じ駅の中でのりばを移動する時間や、別の駅の間を歩いて乗り換える時間（乗換）、同じ場所にある別々の駅をまとめる設定（駅グループ）を管理します。
このタブには、上から「乗換」「乗換の既定値」「駅グループ」の3つの欄が並んでいます。

乗換

一覧には「から」（乗換元の駅とのりば）、「へ」（乗換先の駅とのりば）、「秒数」、「双方向」（オンなら「○」）、「メモ」が表示されます。のりばを指定していない場合は「（指定なし）」と表示されます。
「駅名・かなで絞り込み」の欄に入力すると、乗換元か乗換先の駅名・かなに一致する乗換だけが表示されます。

乗換を新しく作る手順
  1. 「乗換」の見出しの右にある［+ 追加］を押します。「乗換を追加」のフォームが開きます。
  2. 乗換の種類を選びます。
    • 同じ駅の中：同じ駅の中で、別ののりばへ移動する乗換です。
    • 徒歩連絡（別の駅へ）：別の駅まで歩いて乗り換える乗換です。
  3. 乗換元の駅とのりばを指定します。「乗換元」の検索欄で駅を探してクリックすると、「現在: 」の横に選んだ駅が表示されます。続いて「のりば」を選びます。
  4. 乗換先の駅とのりばを指定します。
    • 同じ駅の中の場合：乗換先は自動的に「（同じ駅）」になります。「のりば」の選択欄で移動先ののりばを選びます。
    • 徒歩連絡の場合：「乗換先」の検索欄で駅を探してクリックし、「のりば」を選びます。乗換先の駅を選ばないと乗換元と同じ駅のままになるので、必ず別の駅を選んでください。
  5. 次の項目を入力し、［追加する］を押します（やめたいときは［キャンセル］を押します）。
    • 「秒数」：マイクラの中で、正しい通路をダッシュせずに歩いたときにかかる実際の秒数を、0以上の整数で入力します。
    • 「双方向」：オンにすると、逆向きにも同じ秒数で乗り換えられるものとして扱われます。往復でかかる時間が違う場合は、チェックを外したままにし、行きと帰りをそれぞれ片道ずつ登録してください。
    • 「メモ」：編集者用のメモを入力します（任意）。
のりばの指定についての注意
  • 「同じ駅の中」では、乗換元・乗換先の両方ののりばを指定する必要があり、同じのりば同士は登録できません。のりばが2つ以上ある駅でだけ登録できます。
  • 「徒歩連絡」では、のりばを「（指定なし）」にもできます。
  • 同じ組み合わせの乗換を2つ登録すると、エラーになります。
乗換の変更と削除
  • 変更したいときは、一覧の［詳細］を押してフォームを開き、書き換えて［保存］を押します。
  • 削除したいときは、一覧の［削除］を押し、表示された確認の［削除する］を押します。

乗換の既定値

「乗換の既定値」の欄では、「同じのりばでの乗換秒数」と「不明な場合の乗換秒数」を設定します。この欄には［保存］ボタンがなく、入力欄の値を書き換えて欄から抜けるとすぐに反映されます（0以上の整数のみ入力できます。正しくない値を入れるとメッセージが出て元の値に戻ります）。

この既定値が使われるのは同じ駅の中の乗換だけです。次のように適用されます。

  • 同じのりばで乗り換えるとき：「同じのりばでの乗換秒数」が使われます。
  • 同じ駅の別ののりばへ乗り換えるとき：乗換（同じ駅の中）の登録がなければ、「不明な場合の乗換秒数」が使われます。
  • 別の駅へ歩いて乗り換えるとき：既定値は使われません。乗換（徒歩連絡）を個別に登録しない限り、乗換案内で経路として検索されません。

駅グループ

駅名が違っても同じ場所にある駅をまとめる設定です。グループに入れた駅は、乗換案内で駅名を検索したときに「（○○と徒歩連絡）」と案内が表示されます。
一覧には「グループ名」と、含まれる「駅」が表示されます。

駅グループを作る手順
  1. 「駅グループ」の見出しの右にある［+ 追加］を押します。「駅グループを追加」のフォームが開きます。
  2. 「グループ名」を入力します（例：大阪・梅田）。
  3. 「駅」の表の下の検索欄で駅を探してクリックし、グループに入れる駅を2つ以上追加します。入れた駅を外したいときは、その行の［削除］を押します。
  4. ［追加する］を押します（やめたいときは［キャンセル］を押します）。
  • 同じ駅を2つ以上のグループに入れることはできません。別のグループに入っている駅を含めて［追加する］（［保存］）を押すと、メッセージが表示されます。
  • 駅グループに登録しただけでは、歩いて乗り換える経路として検索されません。実際に乗り換えられるようにするには、乗換（徒歩連絡）を登録してください。
  • 変更・削除の方法は、乗換と同じです（一覧の［詳細］・［削除］）。
次の章6. 運行情報

6. 運行情報

列車の遅延、運休、その他のお知らせなど、利用者に伝える「運行情報」を作成・公開します。
運行情報は路線網とは別のデータ（運行情報）として保存され、状態の行の「運行情報 版 N」が対応します。

Note

運行情報タブに「先に「保存/読込」タブで路線網 (network) と運行情報 (operations) を読み込んでください。」と表示された場合は、運行情報のデータが読み込まれていません。「データの読込と書出」タブの「サーバーから読み込む: 運行情報」で［読み込む］を押してください。

画面の見方

  • 絞り込み：見出しの下にある2つの選択欄で、公開設定の「状態」（「下書き・公開中」「すべて」「下書きのみ」「公開中のみ」「終了のみ」）と路線で絞り込めます。初期状態では「下書き・公開中」だけが表示されます。
  • 一覧：「状態」「路線」「見出し」「原因」「更新日時」が表示されます。各行の右端に［詳細］［複製］［削除］があります。

運行情報を作成する手順

  1. 見出しの右にある［+ 追加］を押します。「運行情報を追加」のフォームが開きます。
  2. フォームの各項目を入力します（各項目は「フォームの項目」を参照）。新しく作った運行情報は、公開設定の「状態」が「下書き」、影響区間が「全線」、方向が両方オン、影響種別が「すべて」の状態で始まります。
  3. フォーム下部の「プレビュー」で、自動作成された見出しと本文を確認します。
  4. ［追加する］を押します。入力に不足があるとメッセージが表示されて反映されません。反映されたあともフォームは開いたままです。
  5. 状態の行の［サーバーに保存］を押します。「公開中」の運行情報は、サーバーに保存した時点で利用者に表示されます。

フォームの項目

  • 影響路線：運行情報の対象となる路線を選びます。影響路線を変えると、影響区間・影響種別・直通の設定は初期状態に戻ります。
  • 公開設定の「状態」：公開するかどうかを「下書き」「公開中」「終了」から選びます。「公開中」にしてサーバーに保存すると、利用者の乗換案内ページなどに情報が表示されます。「下書き」にしておくと非公開のまま保存できます。
  • 発生日時：いつ起きたかを年・月・日・時・分の欄に入力します。新しい運行情報には今年の年が入っています。時刻は空欄でもかまいません。公開設定の「状態」が「下書き」以外のときは、月・日が必須です。
  • 影響区間：
    • 路線全体が対象のときは、「全線」にチェックを入れたままにします（始点と終点に路線の端の駅を選んでも、自動的に全線にはなりません）。
    • 一部の区間だけを対象にしたいときは、「全線」のチェックを外します。「始点」「終点」の選択欄が表示される（最初は路線の駅順の最初と最後の駅が入っています）ので、対象の区間の始点の駅と終点の駅を選びます。
    • 環状線やラケット型の路線では、始点から終点へ「駅順どおりに進む向きの名前」（例：外回り）の方向に進んだ側が影響区間になります（フォームにもこの説明が表示されます）。反対側を対象にしたいときは、始点と終点の駅を入れ替えて選び直します。
  • 方向（列車の進行方向）：影響を受ける列車の進行方向にチェックを入れます。チェック欄には路線の向きの名前（例：下り線、上り線）が表示されます。少なくとも1つにチェックが必要です。
  • 影響種別：すべての種別の列車が影響を受けている場合は「すべて」にチェックを入れたままにします。一部の種別だけが影響を受けている場合は「すべて」のチェックを外し、表示された種別の中から対象の種別にチェックを入れます（1つ以上必要です）。
  • 運行状況の「状態（ステータス）」：運転見合わせや遅延などの運行の状況を、「種類」の選択欄のテンプレートから選びます。新しい運行情報では何も選ばれていないため、必ず選んでください。「お知らせ」「その他」を選んだ場合だけ、「見出し」「本文」を自分で直接入力できます（それ以外のテンプレートでは、テンプレートの文章が入り、編集できません）。
  • 原因：人身事故や車両故障などを「種類」の選択欄のテンプレートから選びます。新しい運行情報では何も選ばれていないため、必ず選んでください。「その他」を選んだ場合だけ、「見出し」「本文」を自分で入力でき、その場合はどちらも必須です。「原因路線の表示」では、原因となった路線を「影響路線と同じ」「別の路線」「表示しない」から選べます。原因の種類を選び直すと、「原因路線の表示」はその種類ごとに決められた初期値に変わるため、種類を選んだあとに確認してください。「別の路線」を選んだ場合は「原因路線」の選択欄が表示されるので、原因の路線を選びます。
  • 折り返し：影響区間の始点や終点の駅で折り返し運転をしている場合に、「始点で折り返し」「終点で折り返し」にチェックを入れます。
  • 直通：影響路線と直通運転している路線がある場合に設定します（有効な運行系統で、影響路線とほかの路線にまたがって走るものがある場合に、その路線が表示されます）。直通運転している路線がなければ「直通設定はありません。」と表示されます。直通運転している路線ごとに行があり、「直通状態」で「影響なし」「直通中止」「直通再開」を選びます。「直通中止」を選んだときだけ、直通を止める向きを「対象」（「相互」「影響路線→直通先」「直通先→影響路線」から、その路線で選べるもの）から選び、「直通先路線に表示」のチェックが使えます。
  • プレビュー：
    • 「自動生成」を選んでいるときは、入力内容から自動で作られた見出しと本文が表示されます。
    • 自動作成された文章を変更したいときは、「手動で書き換える」を選びます。自動作成された見出しと本文が入力欄に入るので、直接書き換えます。「自動生成」に戻すと、手動で書き換えた文章は破棄されます。

Note

入力した内容が、プレビューにすぐ反映されないことがあります。その場合でも、フォームの［保存］（［追加する］）を押すとフォームが開き直され、最新の内容でプレビューが表示されます。
プレビューが自動で更新されるのは、影響路線、公開設定の「状態」、全線、すべて、運行状況の「状態（ステータス）」や原因の種類、原因路線の表示、直通状態などを切り替えたときです。発生日時、始点・終点、方向、種別ごとのチェック、折り返しなどを変えた直後は、反映されないことがあります。

入力のチェック

［保存］（［追加する］）を押したときに次の条件を満たしていないと、メッセージが表示されて反映されません。

  • 影響路線が選ばれていること
  • 公開設定の「状態」が「下書き」以外なら、発生日時の月・日が入っていること
  • 区間を指定する場合は、始点・終点が選ばれていること
  • 方向のいずれかにチェックが入っていること
  • 運行状況の「状態（ステータス）」の種類が選ばれていること
  • 影響種別で「すべて」か、1つ以上の種別にチェックが入っていること
  • 原因の種類が選ばれていること（「その他」なら見出しと本文も入力されていること）
  • 原因路線の表示が「別の路線」なら、原因路線が選ばれていること

そのほかの操作

  • ［キャンセル］（フォーム）：フォームを閉じます。新規作成中、または内容を変更していた場合は「変更を破棄しますか？」と確認が出ます。
  • ［複製］（一覧）：同じ内容の運行情報を「下書き」の状態でもう1つ作成し、そのフォームを開きます。確認なしですぐに一覧に追加されます。
  • ［削除］（一覧）：行に「本当に削除しますか？」と表示されるので、［削除する］を押すと削除されます。
  • 一覧の「更新日時」は、フォームの［保存］（［追加する］）を押した日時です。
次の章7. そのほかのタブ

7. そのほかのタブ

7.1 鉄道会社（鉄道会社タブ）

鉄道会社のIDと名前を管理します。このタブは図形式エディタと同じ画面です。

  • 追加する：一覧の下にある［鉄道会社を追加］を押します。吹き出しが開くので、「会社ID」と「会社名」を入力して［作成］を押します（やめたいときは［キャンセル］を押します）。会社IDは半角の英数字、アンダースコア（_）、ハイフン（-）のみを使い、1〜64文字で入力します。会社IDは作成した後に変更できません。
  • 会社名を変更する・削除する：一覧の会社をクリックすると、その下に「会社名」の入力欄と［鉄道会社を削除］が開きます。会社名は書き換えて欄から抜けるとすぐに反映されます（空にすると元の名前に戻ります）。削除するときは［鉄道会社を削除］を押し、確認ダイアログで［鉄道会社を削除］を押します。
  • 路線から使われている会社は削除できません。「使われているため削除できません。」と使っている路線の一覧が表示され、クリックすると路線タブの該当の路線へ移動できます。
  • 一覧で「KT線」の札が付いている会社は、システム側で自社として設定されている会社のため削除できません。

7.2 車両種別（車両種別タブ）

Minecraft内の列車の仕組み（車両種別）を確認する閲覧専用のタブです。管理者が設定する項目のため、このエディタでは編集できません。新しい仕組みの鉄道を作ったときは、管理者へ連絡してください。

  • TrainCarts：Minecraftのプラグイン「TrainCarts」で動く列車です。
  • 新幹線：氷ブロックの上を滑走するボートです。
  • トロッコ：Minecraft標準のトロッコです。

7.3 履歴（履歴タブ）

過去にいつ・誰がデータを保存したかの記録（更新履歴）を確認します。上部のボタンで「路線網」と「運行情報」を切り替えて確認できます。

  • 一覧には、版数、保存した日時、保存した人が表示されます。一度に50件まで表示され、続きがあるときは一覧の下の［さらに読み込む］を押すと続きを表示できます。［この版に戻す］で作られた版には「ロールバック元: 」が表示されます。
  • 一覧から版を選ぶと、右側に詳しい情報とボタンが表示されます。
  • ［今のデータと比べる］：選んだ版と、今編集しているデータとの件数の差（鉄道会社、駅、路線、運行系統、乗換、駅グループ、運行情報の件数）を確認できます。
  • ［この版を編集中のデータにする］：選んだ版の内容を画面に読み込みます。サーバーには保存されず、未保存の状態になります。未保存の変更がある場合は、変更が失われる旨の確認ダイアログが表示されます。過去の内容を確認したいときや、そこから修正して保存し直したいときに使います。
  • ［この版に戻す］：選んだ版の内容を、新しい版としてその場でサーバーに保存します（確認ダイアログが表示されます）。未保存の変更がある間は使えません。先に現在の変更をサーバーに保存するか、「データの読込と書出」タブでサーバーから読み込み直して変更を取り消してから押してください。

7.4 データの読込と書出（データの読込と書出タブ）

サーバーからデータを読み込み直したり、手元のパソコンにファイルとして保存（書き出し）したり、ファイルから読み戻したりする画面です。ログインやログアウトもこのタブから行えます。データを読み込む前でも、このタブは開けます。なお、このタブの中にサーバーへ保存する機能はありません。サーバーへの保存は状態の行の［サーバーに保存］から行います。

  • ログイン：ログインしていないときは、「ユーザーID」「パスワード」の入力欄、［詳細設定］（接続先の Workers API URL。通常は変更不要）、［ログイン］が表示されます。ログイン中は［ログアウト］が表示されます。
  • サーバーから読み込む：「路線網」と「運行情報」のそれぞれに［読み込む］ボタンがあります。未保存の変更がある場合は、変更が失われる旨の確認ダイアログが表示されます。読み込むと「版 N を読み込みました」と表示されます。
  • ファイルに書き出す：「ファイル: 路線網」「ファイル: 運行情報」のそれぞれにある［ファイルに書き出す］を押すと、路線網は network.json、運行情報は operations.json というファイル名でパソコンにダウンロードされます。
  • ファイルから読み込む：［ファイルから読み込む］を押し、あらかじめ保存しておいたファイルを選びます。
    • 読み込めないとき：ファイルの形式が正しくない場合、ファイルの種類（路線網か運行情報か）が違う場合、内容にエラーがある場合は、メッセージが表示されて読み込みが中止されます。
    • 読み込めるとき：現在のデータとの件数比較が確認ダイアログに表示されます（項目名は英語で表示されます）。［置き換える］を押すと画面に読み込まれます（未保存の状態になります）。
次の章8. 図形式エディタとの行き来

8. 図形式エディタとの行き来

使い分け

  • 表形式エディタ：たくさんのデータを一覧でざっと見直したいときや、一覧で見比べながら1件ずつ直したいときに向いています。
  • 図形式エディタ：駅や運行系統をまとめて新しく作るときや、路線図の全体を見ながら直通運転や乗換の関係を確認したいときに向いています。駅の図の上の位置の調整、元に戻す・やり直す、操作ガイドは図形式エディタだけの機能です。

図形式エディタへの移動

状態の行にある［図形式で編集］を押すと図形式エディタに移動します。
サーバーに保存していない変更がある場合は、「未保存の変更は図形式のエディタに引き継がれません。先にサーバーに保存してください。」という確認ダイアログが表示されます。［保存せずに移動］を押すと、未保存の変更を破棄して移動します。変更を残したいときは［キャンセル］を押し、状態の行の［サーバーに保存］を押して保存してから移動してください。

表形式エディタへの戻り方

図形式エディタの状態の行にある［表形式で編集］を押すと、いつでもこの表形式エディタに戻れます。
